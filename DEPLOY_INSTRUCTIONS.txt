   When prompted for credentials:
   - Username: dw-hurt
   - Password: Use a Personal Access Token (NOT your GitHub password!)
   
   Get Personal Access Token:
   a. Go to: https://github.com/settings/tokens
   b. Click "Generate new token" → "Classic"
   c. Name: Divorce Quest Deployment
   d. Select scope: ✓ repo (check all under repo)
   e. Click "Generate token"
   f. COPY THE TOKEN (you won't see it again!)
   g. Paste as password when PowerShell asks

5. ENABLE GITHUB PAGES
   After successful push:
   a. Go to: https://github.com/dw-hurt/divorcegame
   b. Click "Settings" (top menu)
   c. Click "Pages" (left sidebar)
   d. Source: Select "main" branch
   e. Folder: Select "/ (root)"
   f. Click "Save"
   g. Wait 1-2 minutes
   h. Your game will be live at: https://dw-hurt.github.io/divorcegame/

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "git is not recognized"
SOLUTION: Install Git from https://git-scm.com/download/win
          Restart PowerShell after installation

PROBLEM: "Cannot run script" or "Execution policy" error
SOLUTION: Run this command first:
          Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

PROBLEM: "Permission denied" or authentication fails
SOLUTION: Use Personal Access Token, not GitHub password
          Generate at: https://github.com/settings/tokens
          Token needs "repo" scope (all permissions under repo)

PROBLEM: "Repository not found"
SOLUTION: Make sure the repository exists at:
          https://github.com/dw-hurt/divorcegame
          If not, create it on GitHub first

PROBLEM: GitHub Pages shows 404
SOLUTION: Wait 1-2 minutes after enabling Pages
          Verify Settings → Pages shows "Your site is live at..."
          Check that branch is "main" and folder is "/ (root)"

PROBLEM: Game loads but doesn't work
SOLUTION: Press F12 in browser to check console for errors
          Verify all files were uploaded (check on GitHub)
          Make sure folder structure is correct (css/ and js/ exist)
