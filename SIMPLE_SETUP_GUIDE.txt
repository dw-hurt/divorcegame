AFTER FILES ARE SAVED - DEPLOY TO GITHUB
================================================================================

STEP 4: OPEN POWERSHELL IN YOUR FOLDER
────────────────────────────────────────

Method 1 (Easiest):
  1. Open File Explorer
  2. Go to your divorcegame folder
  3. Hold SHIFT and RIGHT-CLICK inside the folder
  4. Select "Open PowerShell window here"

Method 2:
  1. Open File Explorer
  2. Go to your divorcegame folder
  3. Click in the address bar (top)
  4. Type: powershell
  5. Press Enter


STEP 5: RUN DEPLOYMENT SCRIPT
────────────────────────────────────────

In PowerShell, type these commands:

First time only (allow scripts):
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Then deploy:
  .\DEPLOY_NOW.ps1


STEP 6: AUTHENTICATE WITH GITHUB
────────────────────────────────────────

When prompted:
  Username: dw-hurt
  Password: YOUR PERSONAL ACCESS TOKEN (not GitHub password!)

Get token:
  1. Go to: https://github.com/settings/tokens
  2. Generate new token → Classic
  3. Name: Divorce Quest
  4. Check: repo (all)
  5. Generate and COPY token
  6. Paste as password in PowerShell


STEP 7: ENABLE GITHUB PAGES
────────────────────────────────────────

After successful push:
  1. Go to: https://github.com/dw-hurt/divorcegame/settings/pages
  2. Source: main branch
  3. Folder: / (root)
  4. Click Save
  5. Wait 1-2 minutes

TROUBLESHOOTING
================================================================================

Problem: Can't find PowerShell
Solution: Search "PowerShell" in Windows Start menu

Problem: Script won't run
Solution: Run this first:
          Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Problem: Don't know my username
Solution: In PowerShell type: echo $env:USERNAME

Problem: Files in wrong place
Solution: Check this guide - files must be in css/ and js/ folders

Problem: Authentication fails
Solution: Use Personal Access Token, not GitHub password
